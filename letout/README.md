低连接时代里的一个情绪出口。不是社交、不是心理治疗——只是允许你暂时不用隐藏。

- **演示**：https://955827.xyz/letout
- **仓库**：`github.com/Bortala5827/letout`

## 五种释放方式

说出来 / 喊出来 / 唱出来 / 哭出来 / 安静一下——任选一种，先出声。

核心是**释放** ≠ 社交：录完即结束，不引导分享、不建关系。默认阅后即焚，想留再主动点「留存」。

## 边界
