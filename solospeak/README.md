# SoloSpeak · 独声

让独居者「跟自己说说话」的轻量语音工具。本地优先、隐私优先、零后端——你的声音只属于你。

- **演示**：https://955827.xyz/solospeak
- **仓库**：`github.com/Bortala5827/solospeak`

## 核心

- 按住录音、松开停止，安静地跟自己说一会儿话
- 话题引导（轻 / 中 / 重 三级，60 条），不想说就「换一个」
- 每日目标（默认 30 分钟，动态补差，不制造打卡焦虑）
- 声音日志存本地 IndexedDB，可导出 TXT / Markdown / JSON / .webm
- PWA：可添加到主屏幕，离线可用

## 技术

纯前端、零后端 · 原生 HTML/CSS/ES Modules · IndexedDB + LocalStorage · 托管于 Cloudflare Pages 子路径 `/solospeak`。

## 边界

不是社交、不是心理治疗：不建好友体系、不评价「说得好不好」、不建云端音频仓库。
