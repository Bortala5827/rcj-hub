还能免费用的大模型 API，按国内可用优先排。拿到接口地址、模型名、Key 三样，填进支持自定义模型的客户端即可用。

全部 OpenAI 兼容 chat/completions，鉴权 Bearer Key。
不同客户端的填法略有差异：有的只需填到 /v1（如 b.ai、Gemini），有的要填整条 …/chat/completions（如小红书、商汤）。拿不准就用下方「测试连通性」自测。

小红书 dots（dots.ai） 国内可用 有免费层

小红书 dots studio 的开放平台，模型偏中文生活场景理解，后端默认源就是它。

免费额度开放平台注册即送调用额度（以平台页面为准）
模型dots3-note 系列（如 dots3-note-prev）
填进自定义模型客户端（参考值，以你实测为准）： 接口地址 = https://note3-prev-api.askdiandian.com/v1/chat/completions
模型名 = dots3-note-prev · Key = 平台申请的 Key（Bearer）
注：公开开放平台的接口地址即 askdiandian.com 这个域名（点点 App 后端域），非 dots.ai 官网。

Google Gemini 🌐 海外 · 需代理/反代 有免费层

Google AI Studio 申请 Key 即用，免费档额度足够个人玩。注意要填 OpenAI 兼容端点，别填原生 generateContent。国内调用需反代：generativelanguage.googleapis.com 直连不通，没🪜要走反代域名。

免费额度AI Studio 免费 Tier，有 RPM 限制
模型gemini-3.5-flash-lite（2.0/2.5 已失效，用这个）
填进自定义模型客户端（参考值，以你实测为准）： 接口地址 = https://generativelanguage.googleapis.com/v1beta/openai（填到 /v1 即可，整条全填反而用不了）
模型名 = gemini-3.5-flash-lite · Key = AI Studio 的 Key（Bearer）
不要填原生 :generateContent 地址，会被拼错成 404。国内直连不通时，需把该域名换成可用反代。
