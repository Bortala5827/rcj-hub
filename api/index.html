常见报错速查

401 Key 错误或未加 Bearer 前缀 · 404 接口地址拼错（多/少了 /v1 或 /chat/completions）· 400 model_not_found 模型名拼写错误 · 429 超出免费额度或频率限制 · 500/502 服务端问题，稍后重试或换模型。

⚠️ 自建中转风险提示：自建中转可能违反原模型服务商的使用条款（ToS），存在账号封禁、IP 拉黑、API 限额清零等风险；且相关项目能力依赖上游客户端逆向，稳定性无保障。请谨慎评估合规性与风险后自用，勿对外提供公共服务。

⚠️ 小白劝退：自建中转项目均需一定技术基础（Docker/Node.js/Python/Go 环境配置、网络代理、OAuth 授权等），零基础用户请直接用上方国内可用 API，不要瞎折腾浪费时间。

Y Combinator 孵化，100+ provider 统一网关。Python SDK + Proxy Server 双形态，企业级预算控制、虚拟 Key、自动 fallback。

✅ 实测可用（Windows 11 + Python 3.13）：已验证路由到硅基流动（SiliconFlow），返回正常，token 用量统计准确。

模型示例openai/gpt-4o、anthropic/claude-3-sonnet、google/gemini-pro
部署后填进客户端： 接口地址 = http://localhost:4000/v1（或你的服务器 IP）
