把海外模型统一封装成 OpenAI 兼容接口，自己部署即可国内直连调用。以下项目均为开源，按需选一个自建。

OmniRoute ⭐ 30k+ stars

免费开源 AI 网关，341 个 provider、90+ 免费层。一键本地部署，自动回退配额耗尽的订阅 → API Key → 免费模型。

部署npm install -g omniroute && omniroute 或 Docker
端点http://localhost:20128/v1（本地默认）
模型示例openai/gpt-5.4、glm/glm-5.2、auto（自动选最优）
部署后填进客户端： 接口地址 = http://localhost:20128/v1（或你的服务器 IP）
模型名 = 按需填，如 openai/gpt-4o；用 auto 可自动路由
Key = 留空或用任意值（OmniRoute 管理上游密钥）
GitHub 官网
LiteLLM ⭐ 55k+ stars

Y Combinator 孵化，100+ provider 统一网关。Python SDK + Proxy Server 双形态，企业级预算控制、虚拟 Key、自动 fallback。

部署pip install 'litellm[proxy]' && litellm --model openai/gpt-4o 或 Docker
端点http://localhost:4000/v1（本地默认）
模型示例openai/gpt-4o、anthropic/claude-3-sonnet、google/gemini-pro
部署后填进客户端： 接口地址 = http://localhost:4000/v1（或你的服务器 IP）
模型名 = 按 LiteLLM 格式：openai/gpt-4o、anthropic/claude-3-sonnet 等
Key = 配置在 config.yaml 上游密钥，客户端 Key 可填任意值
GitHub 文档
One API Go 语言 · 轻量

用 Go 写的 API 管理与分发系统，"OpenRouter 的开源替代品"。支持聊天/图像/语音/嵌入多模态，约 28 家模型提供商。

部署下载二进制或 Docker；配置 config.json 添加上游 Key
端点http://localhost:3000/v1（默认端口）
模型示例gpt-4、claude-3-opus、glm-4、deepseek-chat
部署后填进客户端： 接口地址 = http://localhost:3000/v1（或你的服务器 IP）
模型名 = One API 配置的模型别名（如 gpt-4、claude-3-opus）
Key = One API 分配的虚拟 Key
