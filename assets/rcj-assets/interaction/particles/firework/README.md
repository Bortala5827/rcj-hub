# particles/firework · 烟花

**状态：📋 规划中**
**技术：** Canvas
**将用于：** RCJ Hub（里程碑庆祝）、SoloSpeak / FaceTalk（大节点反馈）

## 形态
点击或到达里程碑时，夜空升起烟花，多层粒子爆裂 + 重力下坠 + 拖尾。比 confetti 更「重」的庆祝，留给真正值得的时刻。

## 路线
1. 单次烟花爆发（粒子 + 重力 + 拖尾 + 淡出）
2. 多烟花编排（时间线错落）
3. 配色接入 RCJ 品牌色板

## 复用
粒子物理沉淀进 RCJ Particle Engine，与 confetti / stars / burst 共用。
