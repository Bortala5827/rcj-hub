# 推文内容模板（draft.md 格式）

> 我写推文时按这个格式产出，脚本 `draft_fill.mjs` 直接读取填充。

---

## 格式

```markdown
# 标题（≤64 字，含钩子）

作者：RCJ9527

> 摘要/导语（可选，2 句以内，抓人）

第一段：开门见山，前 3 行必须抓人（列表页只显示标题+摘要+首图）。

## 小节标题

正文……**加粗关键词**……

- 要点一
- 要点二

> 金句/引用

```js
// 代码块
```

![配图位置：此处放产品截图](placeholder)

结尾：诚实收束 + 引导。
```

---

## 标题公式

`（人群/场景）+（动作/结果）+（钩子）`

- 例子：`一个人用 Playwright 给 4 个产品做体检，踩了 10 个坑`
- 例子：`深圳辅警面试 3.0：结构化答题框架 + AI 辅助点评`
- 不写标题党：不承诺结果、不夸大

## 字数规则

| 类型 | 字数 | 场景 |
|---|---|---|
| 贴图 | ≤ 800 字 | 轻量分享、日常更新 |
| 深度长文 | 1500–2500 字 | 教程、复盘、方法论 |

## 结构规则

- 每段 ≤ 4 行，段间空一行（手机阅读）
- 加粗只标关键词，不整句加粗
- 列表最多 5 项，超出拆小节

## 配图规则

- 正文配图位置用 `![配图位置：描述](placeholder)` 标注
- 脚本渲染成灰色占位块「🖼 描述（配图：需在后台手动插入）」
- 后台发布时把占位块替换成真图（上传进微信 CDN）
- 封面图单独在后台设置，不进正文

## 合规检查清单（发布前过一遍）

- [ ] 不夸大 AI 能力（点评类写「录音转文字→基于文字内容点评」，不写「AI 听得出语气/声音」）
- [ ] 不承诺考试结果/通过率
- [ ] 联系方式只走公众号内合规路径
- [ ] 标题 ≤ 64 字
- [ ] 字数符合类型
- [ ] 有配图位置提示或封面方案
