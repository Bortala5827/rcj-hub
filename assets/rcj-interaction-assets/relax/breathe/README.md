# relax/breathe · 呼吸圆圈

**状态：📋 规划中**
**技术：** CSS / Canvas
**将用于：** SoloSpeak（情绪练习引导）、LetOut（平复）

## 形态
一个圆圈随节奏扩大（吸气 4s）→ 缩小（呼气 4s），配合引导文案「吸气…呼气…」。可叠加轻微粒子，让呼吸有「被托住」的质感。适合放在语音日记前做开场，或情绪释放后做收尾平复。

## 路线
1. 纯 CSS 圆圈呼吸动画 + 文案节奏
2. 可选麦克风联动：检测用户是否在呼气（声纹），同步圆圈
3. 多圈层 + 粒子拖尾（接入 RCJ Particle Engine）

## 复用
节奏控制可沉淀为 `motion/` 的通用时间线能力。
