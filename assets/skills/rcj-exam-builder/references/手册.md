# 题库工作流 · 完整上手手册（笔试 + 面试）

> 适用：任何招考（辅警 / 消防 / 应征入伍 / 军队文职 / 公考…）。本手册只覆盖**笔试 + 面试**两类题库。
> 目标：把「自己或 AI 采集的题目与答案」快速变成 **离线 HTML + Anki 卡片（带标签分组/子牌组）+ 可托管到 Cloudflare 的在线站**，且全程**几乎不耗对话 token**。

---

## 0. 总览流程图

```
①采集题目+答案  ──►  ②题目/答案分离（mimocode 或任意工具）──►  结构化 CSV
        （自己整理 / Claude·Gemini 生成答案）        （照模板填，题目不进对话框）
                                                        │
                                                        ▼
              ③调用 rcj-exam-builder（一句话）──► 自动跑脚本：
                 · ingest.py      CSV → data.json（可编辑源）
                 · build_data.py  data.json → data.js（离线运行时）
                 · anki_export.py data.json → anki_cards.csv / .apkg（带标签分组）
                 · viewer.html    复制成 index.html / written.html（离线查看器）
                                                        │
                          ┌─────────────────────────────┼─────────────────────────┐
                          ▼                             ▼                         ▼
                    ④离线 HTML                   ⑤ Anki 卡片               ⑥ 推 GitHub
              （双击 file:// 即用，           （导入即背，标签分组/子牌组）    → 托管 Cloudflare
                🎲随机抽题 / 面试🎤录音）                                    （在线版静态站）
```

**省 token 关键**：题目全文只存在于 `CSV / json / md` 文件里，对话里你只发「处理 `XXX.csv`」一句话，AI 跑脚本读文件，题目正文**从不进聊天记录**。

## 1. 环境准备

- **Python 3**（ingest / build_data / anki_export 纯标准库，零依赖；只有 `.apkg` 才需 `pip install genanki`）
- **PDF / Word 直读（可选）**：想直接丢 `.pdf` / `.docx` 原始题库才需要
  `python -m pip install pypdf python-docx`
- 一个能整理表格的工具：Excel / WPS / **mimocode** / 或让任意 AI 帮你整理都行
- 可选：**node**（仅做 `node --check` 校验，没有会自动跳过）

---

## 2. 采集题目与答案

两种方式任选，结果都要落到**结构化文件**：

- **自己整理**：从教材 / 真题卷里摘录。
- **AI 生成**：把原始材料丢给 Claude / Gemini，让它输出「题目 + 答案」（可批量生成）。

无论哪种，下一步都是把「题」和「答案」**分离并结构化**——这就是 mimocode（或任意表格工具）的用武之地。

---

## 3. 题目 / 答案分离 → 结构化 CSV（最小 token 的核心）

用 mimocode（或 Excel/WPS/AI）把内容整理成下面两种模板之一，**存成 `题目.csv`**。
模板就在 skill 里：`assets/题库模板.csv`（笔试）、`assets/题库模板_面试.csv`（面试）。

### 笔试模板（`题库模板.csv`）列：
`题号,批次,题型,题干,选项A,选项B,选项C,选项D,答案,解析,标签`
- 题型填：单选 / 多选 / 判断 / 填空 / 简答
- 多选答案写 `A,C`；判断写 `对`/`错`；不考的填空留空
- 解析、标签可空

### 面试模板（`题库模板_面试.csv`）列：
`年份,场次,题型,标题,答案,标签`
- 题型填分类名，如 `自我认知与职位匹配` / `应急应变`（原样保留）
- 答案整段写，不被逗号拆；没有答案就留空（字段会预留，日后补）

> 若你手里是 **PDF / Word / 纯文本 / markdown**，可跳过手填模板，直接让 skill 自动切题（见第 6 节方式一）。

---

## 4. 调用 skill 自动生成（一句话）

把 `题目.csv` 放进项目目录，对 AI 说：

> 用 rcj-exam-builder 处理 `题目.csv`：①拆进 `data.json` ②生成离线 `data.js` ③导出 Anki 卡片（CSV，按年份+题型分组）④复制 viewer.html 作为离线查看器。

AI 跑的脚本（你也可自己复制执行）：

```bash
# 笔试
python scripts/ingest.py   题目.csv        -o data-written.json
python scripts/build_data.py data-written.json -o data-written.js --global-name DATA_WRITTEN --minify
python scripts/anki_export.py data-written.json --group-by batch,type -o anki_written.csv

# 面试
python scripts/ingest.py   面试题目.csv     -o data-interview.json
python scripts/build_data.py data-interview.json -o data-interview.js --global-name DATA_INTERVIEW --minify
python scripts/anki_export.py data-interview.json --group-by year,type -o anki_interview.csv

# 离线查看器（笔试+面试合一模板）
copy assets/viewer.html index.html        # 合并站：同目录放 data-written.js + data-interview.js

# 站点可编辑配置（标题/闲鱼号/倒计时，改 template-config.json 即可，不用碰 HTML）
copy assets/template-config.sample.json template-config.json   # 先放一份配置源
python scripts/build_data.py data-written.json -o data-written.js --global-name DATA_WRITTEN --minify ^
       --config template-config.json --emit-config config.js
# 提示：config.js 由上面 --config 一并生成；以后改标题/闲鱼号只编辑 template-config.json 重跑这条即可
```
> 关键：`build_data.py` 必须带 `--global-name DATA_WRITTEN` / `DATA_INTERVIEW`，否则生成的是 `window.DATA`，合并模板会退化成单模式。改题只重跑这两条命令重新生成 `data-*.js`，HTML 不动。
> 站点配置（标题/闲鱼号/倒计时）：编辑 `template-config.json` 后重跑带 `--config` 的那条命令重新生成 `config.js`，HTML 不动。

产物一览：

| 产物 | 用途 |
|---|---|
| `data-written.json` / `data-interview.json` | 可编辑源，以后改题只动这里 |
| `data-written.js` / `data-interview.js` | 离线 HTML 运行时（`file://` 双击即用） |
| `anki_written.csv` / `anki_interview.csv` | 导入 Anki 复习 |
| `anki_*.apkg`（可选 `--apkg`） | 双击直接装进 Anki，自动建子牌组 |
| `index.html`（合并站） | 离线查看器（笔试/面试 tab 切换、随机抽题、面试录音） |

## 5. 离线 HTML 查看器（笔试+面试合一模板）

`viewer.html` 是**笔试+面试合一的通用模板**，吸收原精致 UI（深色模式 / 渐变头部 / 搜索筛选 / 掌握度 / 🎲随机抽题+3分钟倒计时 / 面试🎤录音演练+语音转文字 / 闲鱼口令 / 撒花），功能：

- **笔试/面试 tab 切换**：同目录放 `data-written.js`(笔试) + `data-interview.js`(面试)，顶部一键切换；掌握度按模式隔离。只有一套题时自动只剩一个 tab。
- **🎲 随机抽题**：一键随机跳到任一道（键盘 `R`/`N` 也行），带 3 分钟考场倒计时。
- **面试🎤录音回答**：点「开始录音」录下口述回答，可回放、可下载；支持语音转文字实时预览（需 HTTPS / 科学上网）。
- **笔试选项高亮**：展开后正确选项绿色高亮，附解析。
- 搜索、按年份/批次/题型/标签筛选、展开全部、只看未掌握、📝套题模考一应俱全（站点不提供「导出题目/打印」按钮，离线卡组请用 `anki_export.py` 在构建期生成）。
- **判断题自动规范化**：数据里判断题选项若写成 `{letter:"正确", text:"正确"}`，模板会自动映射为 `A/B` 显示，避免"正确。正确"这种无法分辨的界面。

**用法**：把 `viewer.html` 复制为 `index.html`，与 `data-written.js`+`data-interview.js`+`config.js` 放同一目录，双击即开。换题库只重新跑 `build_data.py --global-name` 生成新的 `data-*.js`；改站点标题/闲鱼号/倒计时只改 `template-config.json` 重跑带 `--config` 的命令生成新 `config.js`——**HTML 模板始终不用动**（模板 / 数据 / 配置三者解耦，离线 `file://` 也生效）。

## 6. 导入 Anki（标签分组 / 子牌组）

### CSV（嵌套标签 = 分组）
Anki → 文件 → 导入 → 选 `anki_*.csv` → 字段分隔符选**逗号** → 映射 `正面 / 反面 / 标签` → 导入。
- 标签列里的 `2024::综合分析` 会被 Anki 识别为**嵌套标签**，左侧「标签」面板可展开成树状分组，点一下即筛选该组全部卡片。
- 导出时加 `--group-by year,type`（或 `batch,type`）即可自动生成这种分组标签。

### APKG（真·子牌组，推荐想要牌组树的用户）
```bash
python scripts/anki_export.py data-interview.json --apkg --subdeck-by year,type --deck "示例考试面试"
```
双击 `.apkg` 直接装进 Anki，自动生成 `示例考试面试::2024::综合分析` 这种**真正的子牌组**（牌组面板里的树）。比 CSV 嵌套标签更直观。

## 7. 推 GitHub → 托管 Cloudflare（在线版 + 独立文件夹）

为部署专门建一个**干净的站点文件夹**（与源 CSV / 脚本分开），只放要上线的产物：

```
my-exam-site/                ← 这个文件夹整个推 GitHub
├── index.html               # 合并查看器（viewer.html 改名，笔试/面试 tab 合一）
├── data-interview.js        # 面试运行时（build_data.py --global-name DATA_INTERVIEW 生成）
├── data-written.js          # 笔试运行时（build_data.py --global-name DATA_WRITTEN 生成）
├── anki_interview.csv       # 面试卡片（或 .apkg）
├── anki_written.csv         # 笔试卡片（或 .apkg）
├── _headers                 # 缓存策略（复制 assets/headers_template.txt）
└── README.md
```
> 合并站只需一个 `index.html` + 两个 `data-*.js` 即可笔试面试双用；若想拆成两个独立页面，把 `viewer.html` 分别复制成 `index.html`/`written.html` 各配一个 `data-*.js` 也行（此时可省略 `--global-name`，用默认 `window.DATA`）。

步骤：
1. 在 GitHub 新建仓库（如 `my-exam`）。
2. 把 `my-exam-site/` 内容 push 上去。
3. Cloudflare Pages → 连接 Git 仓库 → 构建设置选「**无 / None**」→ 输出目录 `/`。
4. 部署完得到 `https://xxx.pages.dev` 域名；以后改题只需重跑脚本、push 新 `data-*.js`，**自动重新部署**。
5. `_headers` 让 `data-*.js` 走「CDN 长缓存 + 浏览器每小时校验」（`max-age=3600, s-maxage=86400`），HTML 短缓存，二次访问秒开且改题最迟 1 小时生效，无需改文件名。
> 想要「网页改题即自动重建上线」的完整模板（含 `template-config.json` / `build_data.py` 入库 / GitHub Actions 自动构建），见 `references/quiz_template.md` 的 `quiz-template/` 布局。
> 详细部署：见 `references/deploy_cloudflare.md`。

## 8. 复用给其他考试（示例 A → 示例 B → 消防）

这套 skill **不绑定任何地区/警种**。换考试只做两件事：
1. 换**源 CSV**（新的题目+答案，照模板填，或用新 PDF/Word 跑 `doc_to_csv.py`）。
2. 换**页面文案**（HTML 标题等，可选）。
然后跑同一套脚本，**无需重新调试**。

## 9. 常见问题

- **麦克风录音在 `file://` 被拦？** 浏览器要求安全上下文。把站点部署到 Cloudflare（HTTPS）后用录音即可；离线双击场景可用「显示答案」对照练习，录音功能上线后用。
- **扫描版图片 PDF 抽不出字？** 先 OCR 转文本，再丢给 `doc_to_csv.py`；文本型 PDF 才直接支持。
- **Anki 导入逗号分隔？** 字段内含逗号（如多选 `A,C`）会被自动加引号，分隔符务必选「逗号」而非「制表符」。
- **想要真正子牌组而不是标签？** 用 `--apkg --subdeck-by`，不要只导 CSV。
- **改了题不生效？** 离线场景清一下浏览器缓存；Cloudflare 场景本 skill 的 `_headers` 已改为「CDN 长缓存 + 浏览器每小时校验」（`max-age=3600, s-maxage=86400`），改题最迟 1 小时生效、无需改文件名。若你自行把 `data-*.js` 设了 `immutable`，则换题须把文件名改成 `data.v2.js` 并同步改 HTML 引用才能破缓存。
